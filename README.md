## ⚙️ How I Work

```mermaid
flowchart LR
    A([Idea]) --> B[Design<br/>and ADR]
    B --> C[Infrastructure<br/>as Code]
    C --> D[CI: build, test, scan]
    D --> E[CD: progressive<br/>rollout]
    E --> F[Observe: metrics,<br/>logs, traces]
    F -->|feedback| B

    style A fill:#64FFDA,stroke:#0F2027,color:#0F2027
    style F fill:#64FFDA,stroke:#0F2027,color:#0F2027
```

> **Principle:** if I have to do it twice, it gets scripted. If it breaks twice, it gets a dashboard and an alert.
